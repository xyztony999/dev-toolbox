# 初始化决策记录

- ADR-001（用户确定）：独立新项目 DevToolbox；原项目作为迁移来源。
- ADR-002（用户确定）：Go 核心 + Go WebView 宿主 + Vue 3 + Ant Design Vue；不采用此前讨论的 Electron 方向。
- ADR-003（工程方向）：Go 应用服务共用；gitid 语义移植到 Go，以沙箱行为规格对比；不保留最终 Node 核心依赖。
- ADR-004（盘点驱动）：项目/仓库/模块分离；覆盖 Node、Java、Python、Go 及已有 Maven/Gradle/Android 能力，支持显式非 LTS JDK 与严格 Python 约束。
- ADR-005（盘点驱动）：Rust/Tauri、ARM 工具链先检测/导入；数据库与容器仅作为后续诊断扩展候选。
- ADR-006（工程方向）：共享要求与本机绑定分开；Git 配置与运行时环境分别按其原生机制计算。
- ADR-007（工程方向）：会话/子进程优先；全局默认显式操作；不宣称 GUI 能改写已开父终端。
- ADR-008（工程方向）：旧数据只读发现，迁移执行时预览/备份/幂等；不抢占已有命令和配置所有权。
- ADR-009（用户补充）：保留 DevSwitch 用户级运行时状态，包括七种工具各自的全局当前选择，以及运行时清单中的版本、路径、来源、label/vendor；项目和会话覆盖不得改写这些全局选择。

本节不替代完整架构设计或 Gate 1。待后续设计：桥接 schema、数据迁移 schema、冲突优先级、终端恢复、版本 provider、发布与安装标识。
