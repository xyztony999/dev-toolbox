# 产品不变量

适用本业务 profile；凡违反以下条目，业务验证不得通过。

1. Git 实际配置为事实源；档案不写“已应用身份”真值。保留按仓库与目录来源解析，不引入 Git hook 或守护进程自动写身份。
2. 身份应用为全量覆盖：档案缺少的签名、自定义键、URL 重写和账号选择器按受管规则清除；不得残留前一身份。远程镜像仅作用于仓库本地。
3. token 不落档案、不进日志、广播状态或通用桥接结果、不回显。优先通过系统 helper 登录；若设计手工 PAT 输入，必须有单独审查的一次性通道、即时清理与测试。
4. 核心业务逻辑唯一来源为 Go 应用服务；CLI/GUI/托盘不得各维护一套规则。
5. 项目共享要求不携带私有路径、个人身份选择或凭据；本机绑定与共享清单分离。
6. 项目会话不能隐式修改全局默认；不声称 GUI 可修改既有父终端环境。应用结果区分成功、失败、跳过和尽力回退，不能把跨模块副作用伪装成原子事务。
7. 扫描只读，不能执行清单 scripts、Wrapper、hooks 或项目任意命令。版本不明要显示 unknown，不擅自使用 latest。
8. 旧配置迁移必须有来源、预览、备份、幂等记录；不与原工具同时写旧配置、不抢占原命令。卸载仅清理本产品拥有的资产。
9. 测试使用独立 HOME/USERPROFILE/APPDATA/XDG_CONFIG_HOME、Git config/helper 和 OS 适配器；真实 PATH/注册表/shell profile/Git 配置均不可写。
10. Java 编译目标、toolchain、构建 JVM 和 Wrapper 分开建模；Python 系统解释器与项目 venv 分开，尊重现有包管理器所有权。
