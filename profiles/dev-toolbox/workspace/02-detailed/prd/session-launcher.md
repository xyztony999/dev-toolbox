# PRD — 会话启动器

版本：v1.0 | 日期：2026-11-03 | 模块：session-launcher | 状态：Gate 1 待检查

## 1. 目标

用户从项目视图一键打开"环境正确"的终端：按用户级全局选择注入运行时环境（PATH/JAVA_HOME），cwd 为项目/仓库根，多会话并存且绝不影响全局与其它会话。

## 2. 功能需求

| ID | 需求 | 验收标准 |
|---|---|---|
| SL-01 | 上下文求值 | 八工具逐项给出：注入（版本/bin 目录）或未注入（未选择/路径不可用，原因可见） |
| SL-02 | 环境组装 | PATH 前置选中运行时 bin（顺序稳定、去重）；JAVA_HOME=选中 JDK；其余继承父环境 |
| SL-03 | 终端枚举 | Windows 列出 PowerShell/cmd/Git Bash（仅探测存在的）；Linux 列 $SHELL 回退 bash |
| SL-04 | 启动会话 | 新终端窗口以所选 cwd 与注入 env 打开；连续启动多会话互不影响 |
| SL-05 | 不碰全局 | 启动前后 GlobalRuntimeSelection、用户/系统环境变量、shell profile 均无变化 |
| SL-06 | Git 身份预览 | 预览显示 cwd 生效身份（复用既有解析）；不写任何 git 配置 |
| SL-07 | cwd 校验 | 仅接受存在的目录；默认项目根，可指定项目内仓库根 |
| SL-08 | 失败如实 | 终端可执行缺失/启动失败返回稳定错误码，不静默 |
| SL-09 | 注入透明 | 终端内可见当前注入（PATH/JAVA_HOME 与父环境的关系可被人直接验证，如 `echo $env:JAVA_HOME`） |

## 3. 状态与流转

无状态机：preview（幂等只读）→ open（显式动作）→ 进程创建成功即完成。

## 4. 安全与可靠性

终端进程经参数数组启动、显式 env、明确 cwd；不执行任何项目命令；探测仅查文件存在性。注入仅限子进程树——文档与界面均不宣称影响已打开终端。
