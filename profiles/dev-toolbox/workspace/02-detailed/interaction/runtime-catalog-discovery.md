# PageSpec — 本机运行时发现与登记

版本：v1.0 | 日期：2026-10-27 | 模块：runtime-migration | 状态：Gate 1 待检查

## 页面入口

从“用户级运行时设置”进入“发现本机运行时”侧面板/对话框。全局默认视图沿用 `user-runtime-state-migration` PageSpec；本页只增加候选扫描和登记。

## 候选列表

- 扫描来源：当前 PATH 与有限常见目录；用户可输入完整路径并选择工具类型进行单目录检查。
- 字段：工具、版本/unknown、安装目录、来源、证据摘要、可用性、重复/冲突状态、选择框。
- 状态：初始说明、扫描中（可取消）、空结果、部分结果、完整结果、错误及重试。
- 可登记：证据和目录复核成功且未重复。选择候选后出现登记确认摘要。

## 用户动作与反馈

| Action | Go operation | 结果 |
|---|---|---|
| 扫描 | `runtime.discover` | 填充候选及问题列表，不写状态 |
| 添加目录预览 | `runtime.inspectPath` | 显示单候选或稳定分类错误 |
| 确认登记 | `runtime.register` | 刷新用户状态；显示新建/已存在/跳过数量 |
| 取消 | 本地 | 不产生副作用 |

## 作用域与键盘

登记只影响当前用户的 DevToolbox RuntimeCatalog；不自动设置默认、不改变项目或会话。表格支持键盘勾选、清晰焦点、窄窗口滚动；提交期间禁止重复登记。

## API 对齐

字段与操作均取自 `api-runtime-catalog.md`。路径、来源、版本、证据来自 Go 响应；前端不探测文件系统。unknown、unavailable、partial 与冲突不可隐藏。
