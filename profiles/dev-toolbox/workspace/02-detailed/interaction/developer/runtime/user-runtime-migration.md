# PageSpec 草案 — 用户级运行时设置迁移

版本：v1.0 | 日期：2026-10-27 | 归属：user-runtime-state-migration | 状态：本切片 Gate 1 PASS

## 全局运行时设置

- 逐工具展示全局默认选择及其对应的本机运行时条目。
- 展示版本、来源、可用状态、label/vendor；路径只在本机详情中展示。
- 每个条目提供“设为全局默认”；明确提示该操作影响未设置项目覆盖的后续启动会话，不修改已打开终端。
- 项目/会话覆盖显示其作用域，不显示成全局真值。

## DevSwitch 导入预览

- 只读发现来源 state.json 后由用户主动进入预览。
- 预览面板分为：全局默认映射、runtime 清单、路径不可用/未知项、将创建的备份。
- “导入”前显示来源路径、schema、摘要；执行需要明确确认。
- 未知 schema 阻止导入；来源变化要求重新预览；重复导入显示已有导入记录。
- 不显示 JSON 原文，不提供自动修复旧 state.json、搬移安装目录或调整 shell profile 的操作。
