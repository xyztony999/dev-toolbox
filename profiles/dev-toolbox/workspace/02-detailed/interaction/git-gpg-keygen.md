## 2. Action 定义

| Action | op | 触发 |
|--------|-----|------|
| 加载选项 | `git.keygenOptions` | 打开「生成密钥」子面板时 |

## 4. 档案编辑抽屉 —「提交签名」分组增强

在既有字段（signingkey 输入、gpgSign 开关、gpg.format 下拉）下方增加操作区，不拆除手填能力（x509 / 手工指纹仍可手填）。

### 4.1 操作入口

- 按钮「生成密钥」：打开内嵌折叠面板或二级抽屉（与 Remote 面板同一交互语言）。
- 按钮「选用本机密钥」：打开列表选用面板。
- 生成/选用成功后：回填 signingkey、gpg.format，并按用户勾选设置 gpgSign；抽屉内提示「已写入当前档案，保存档案后才会持久化」——**工程默认**：若 `git.keygenCreate` 已直接写 ProfileStore（见 API），则文案改为「已更新档案的签名字段」；与 API 一致采用**服务端已写档案**，前端刷新档案详情，无需再点一次「保存」才能有签名字段。未保存的其它表单脏字段保留。

### 4.2 生成面板字段

| 字段 | 组件 | 说明 |
|------|------|------|
| 密钥类型 | a-radio-group | OpenPGP / SSH 签名 |
| 算法 | a-select | 选项随类型变化；默认 ed25519 |
| 有效期 | a-select | OpenPGP：永不过期 / 1 年 / 2 年 / 5 年；SSH：固定文案「SSH 密钥无到期」且控件禁用 |
| 口令 | a-input-password | 可选；placeholder「可留空」；提交成功或关闭面板后清空 |
| 打开提交签名 | a-switch | 默认开；对应 enableGpgSign |
| SSH 输出路径 | a-input + 浏览 | 仅 SSH；placeholder 显示将使用的默认路径；浏览用 `app.pickFolder` 选目录后拼文件名或选文件 |

校验：类型与算法不匹配时控件层禁用非法项；预览失败在面板内展示错误码对应说明。

### 4.3 预览与确认

- 「预览」展示：将使用的工具路径、步骤摘要（口令显示为「（已设置，不展示）」或「（未设置）」）、将写入的 gpg.format / gpgSign、若档案已有 signingkey 则警告「将替换现有签名密钥引用」。
- 「生成」：二次确认标题「生成并写入档案」；正文列类型、算法、档案 id；无感叹号堆砌。
- 成功：展示指纹或公钥路径 + 「复制公钥」+ 「导出到文件」；失败：面板内错误，保留已填参数（口令除外，失败后亦清空口令框以免误贴日志）。

### 4.4 选用本机密钥

- Tab/段：OpenPGP | SSH。
- 表格列：指纹或路径、UID/注释、（可选）创建时间；行操作「选用」。
- 空态：「未找到可用密钥。可先生成，或检查本机是否已安装 gpg / 是否已有 ~/.ssh 下的公钥。」
- 工具缺失：横幅「未检测到 gpg，请安装后再试」/「未检测到 ssh-keygen」——用 options.available 判定，不假装有列表。

### 4.5 导出

- 「复制」：写入系统剪贴板（公钥文本）。
- 「保存到文件」：原生选路径 → `git.keyExport`；目标已存在时确认「文件已存在，要覆盖吗？」对应 overwrite。

## 5. 状态覆盖

| 状态 | 表现 |
|------|------|
| 工具缺失 | 禁用生成/列表主按钮 + 说明安装提示 |
| 档案无 name/email | OpenPGP 生成前置提示「档案需要姓名和邮箱」 |
| 预览 wouldFail | 禁用生成，展示原因 |
| 部分成功（密钥已生成档案未写） | 警告条 + 指纹/路径 + 「写入档案」快捷调用 select |
| 加载中 | 按钮 loading，防重复提交 |
| 无密钥 | 空态文案见上 |

## 6. CLI 提示（非 GUI）

成功输出指纹/路径与档案 id；错误输出稳定 code。`--passphrase-stdin` 说明写在 `--help`：从标准输入读入口令，避免出现在命令行历史。

## 7. API 对齐

六个操作与 `api-git-gpg-keygen.md` 一一对应；字段名与枚举 code 一致；前端不拼 gpg/ssh 命令。

## 8. 与既有 PageSpec 关系

本文件为增量规格；实现时改 `git-identity` 档案编辑抽屉，不新增路由。`git-identity.md` 在实现阶段可补一句交叉引用；本设计阶段以本文件为交互唯一信息源。
