# PageSpec — 会话启动器

版本：v1.0 | 日期：2026-11-03 | 模块：session-launcher | 状态：Gate 1 待检查

## 项目详情页（主入口）

项目头操作区新增「在此打开终端」按钮：

- 点击展开面板：
  - **环境预览**：八工具逐行（工具名 + 版本 + "注入" tag，或"未注入·原因"），JAVA_HOME 行（设置/继承），"PATH 前置 N 项"摘要，生效 Git 身份行（复用身份页样式）。
  - **cwd 选择**：项目根默认，项目内多仓库时下拉可选仓库根。
  - **终端选择**：单选组（仅列出可用终端），默认第一个。
  - **启动按钮**（主操作）：确认弹窗一句话说明"新终端仅本会话生效，不改全局默认与已打开终端"。
- 启动成功 toast（终端 id + pid）；失败显示错误码。

## 仓库卡片（次入口）

每个仓库行内「打开终端」快捷按钮：以该仓库根为 cwd 直接展开同一面板（预填 cwd）。

## 状态与键盘

覆盖：全未选择（全部"未注入·未选择"，仍可启动=纯继承环境）、部分不可用、无可用终端（按钮禁用+原因）、cwd 失效。面板与选择可键盘操作。

## API 对齐

`session.preview`/`session.open` 字段与 D3 一致；预览数据驱动整面板，无前端自行推断。
