# PageSpec — 仓库 Git Remote 管理

版本：v1.0 | 日期：2026-11-03 | 模块：git-remote-management | 状态：Gate 1 待检查

## 项目详情页（主入口）

仓库卡片行尾新增「Remote」操作：

- 点击展开内联面板（a-collapse 或 drawer）：每个 remote 一行——名字（粗体）、fetch 地址（可点击复制）、push 地址数与镜像标记（⊕）、生效账号；行内小按钮：改地址、重命名、删除。
- 面板顶部「新增 Remote」（名字 + 地址 + 确认）。
- 镜像：每行「镜像推送」开关/按钮组（设置镜像地址 → 开启；已镜像 → 取消）。
- 删除/重命名/改地址均弹确认（删除展示当前地址）；操作成功后面板数据即时刷新，失败显示稳定错误码。

## Git 身份页（次入口）

「迁移与凭据」现有镜像区块旁提供「打开完整管理」跳转提示；行为同上（手输仓库路径场景）。

## 状态与键盘

覆盖：无 remote（空态引导新增）、非仓库路径报错、重名、非法名字/地址（表单即时校验）、镜像已存在。面板可键盘操作；镜像/账号状态有文字不只靠颜色。

## API 对齐

六个操作与 api-git-remote-management.md 一一对应；写操作响应即刷新数据源。
