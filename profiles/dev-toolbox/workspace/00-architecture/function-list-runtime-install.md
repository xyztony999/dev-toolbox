# 功能清单 — 运行时下载与安装

版本：v1.0 | 日期：2026-10-28 | 用户类型：本机开发者

## 运行时获取

- 选择工具、provider 镜像和来源支持的版本通道；显示具体可获得版本及平台支持。
- 预览实际版本、目标目录、校验方式、空间要求和已存在目录冲突。
- 用户确认后下载/验证/安装；展示进度、取消、重试与分步错误。
- 完成后刷新 RuntimeCatalog；用户可另行显式将该实例设为全局默认。

## 空状态与错误

- provider 无匹配版本、平台/架构不支持、离线、无磁盘空间、checksum 缺失/不符、解包拒绝、目标冲突均可见。
- Android SDK 分别报告 platform-tools 与 cmdline-tools 阶段。

## 本模块不提供

卸载、系统 PATH 修改、全局自动切换、项目自动安装和任意 URL 输入。
