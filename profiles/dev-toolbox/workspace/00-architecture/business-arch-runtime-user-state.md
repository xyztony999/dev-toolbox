# 业务架构 — 用户级运行时状态迁移

版本：v1.0 | 日期：2026-10-27 | 模块：user-runtime-state-migration

## 业务域与阶段

本切片属于平台支撑域，为本机用户从旧运行时管理工具接续到 DevToolbox 提供可审阅的数据导入。

| L3 关键业务 | L4 业务活动 | 输出 |
|---|---|---|
| 用户运行时状态迁移 | 查看旧状态来源 | 可读性、schema 与摘要 |
| 用户运行时状态迁移 | 预览导入结果 | 七类工具默认选择与运行时条目映射、异常项 |
| 用户运行时状态迁移 | 确认导入 | 新产品用户状态、原文件备份和导入记录 |
| 用户运行时状态维护 | 查看全局默认 | 用户级工具选择与路径可用状态 |

## 业务规则

- 用户主动确认才导入；旧状态只读并保持原位。
- 全局选择按 tool+本机路径映射；路径缺失时保留为 unresolved，不替用户改选。
- 项目/会话选择是覆盖层；导入及项目扫描都不改变全局默认。
- 新产品备份是导入的前置步骤；失败时不写入目标用户状态。

## 用户

本机 DevSwitch 用户；无服务端账号或跨设备同步。
