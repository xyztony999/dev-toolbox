# 应用架构 — Git 身份密钥生成

版本：v1.0 | 日期：2026-11-27 | 模块：git-gpg-keygen

## 1. 服务边界

| 服务 | 职责 |
|---|---|
| KeygenService（拟扩展 `internal/gitidentity`，如 `keygen.go`） | 探测本机 `gpg`/`ssh-keygen`；枚举算法与有效期选项；预览生成计划；调用本机工具生成；列表本机密钥；写回档案签名字段；导出公钥 |
| ProfileStore（既有） | 校验档案存在；按既有 Upsert/部分字段更新语义写回 signingKey、gpgFormat、gpgSign |
| ToolRunner（进程适配） | 参数数组 + context 超时 + 明确 env（含临时 GNUPGHOME/测试沙箱）；口令仅经 stdin/管道短时传入 |

## 2. 应用域归类

| 分层 | 功能模块 | 说明 |
|------|---------|------|
| 支撑业务域 | 身份密钥生成 | 为核心「身份档案」补齐密钥材料；无独立聚合状态机 |

### 功能模块：身份密钥生成（C/S 支撑）

**功能说明**：同一入口按类型分支，完成 OpenPGP/SSH 密钥的生成、本机列表、选用写回与公钥导出。

**涉及用户类型**：- [✓] 本机开发者

#### 子模块：生成与预览

**功能说明**：校验参数与工具可用性；预览将执行的本机命令摘要（不含口令明文）及将写入档案的字段；确认后生成并写回档案。

**涉及用户类型**：- [✓] 本机开发者

**调用关系**：

| 调用模块/子模块 | 调用说明 |
|---------------|---------|
| 身份档案（既有 ProfileStore） | 校验档案存在并更新签名字段 |
| 本机 gpg / ssh-keygen | 参数数组调用，产物仅指纹/路径/公钥 |

#### 子模块：列表与选用

**功能说明**：列出本机已有 OpenPGP / SSH 签名可用密钥摘要；用户挑选后写回档案，不生成新密钥。

**涉及用户类型**：- [✓] 本机开发者

**调用关系**：

| 调用模块/子模块 | 调用说明 |
|---------------|---------|
| 身份档案 | 写回 signingkey + gpg.format（+ 可选 gpgSign） |

#### 子模块：公钥导出

**功能说明**：按指纹或路径导出公钥文本，或写入用户显式选择的文件路径。

**涉及用户类型**：- [✓] 本机开发者

**调用关系**：无（只读工具调用）

## 3. 调用关系（总览）

```
CLI / WebView
    └── gitidentity 应用服务（白名单增补 git.key* / git.keygen*）
            ├── KeygenService → gpg | ssh-keygen
            └── ProfileStore（既有）
```

前端不拼任何 gpg/ssh 命令；CLI 与桌面共用同一服务。

## 4. 数据与副作用

| 动作 | 副作用 |
|------|--------|
| options / list / export / preview | 无档案写；可能只读探测本机密钥环/目录 |
| create / select（confirm） | 本机生成密钥文件或密钥环条目（用户本机工具管辖）+ 更新产品档案 JSON 中签名三字段 |
| 永不 | 持久化口令、私钥正文、把私钥写入档案或日志 |

测试隔离：临时 `GNUPGHOME`、临时 SSH 目录；不触真实用户默认密钥环（契约测试层强制）。
