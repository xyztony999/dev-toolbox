# 功能清单 — DevToolbox（全局）

版本：v2.0 | 日期：2026-11-11 | 用户类型：本机开发者（单一角色） | 与 BA/AA v2.0 联动

## 导航结构（全局能力）

侧边栏三入口与领域一一对应：项目上下文（核心-项目）、用户级运行时设置（支撑-运行时）、Git 身份（支撑-Git）；已登记项目列表直达项目详情。

## 项目上下文

- 登记：原生目录选择 + 扫描预览 + 确认登记。
- 项目详情：摘要卡（目录/扫描时间/状态）；仓库列表（Git 信息：分支/remote/项目级身份）+ 就地「管理 Remote」（增删/改名/改地址/镜像）与「终端」快捷入口；构建模块（cargo 等构建系统 + 版本要求来源/置信度）。
- 「在此打开终端」：环境预览（八工具注入/未注入、JAVA_HOME、PATH 前置、生效身份）→ cwd/终端选择 → 确认启动。

## 用户级运行时设置（四标签）

- 全局默认：八工具逐行生效状态与设为默认。
- 获取运行时：provider 预览→确认→下载安装（进度/取消/重试）。
- 发现与登记：本机扫描/指定目录检查/外部工具链（rustup/uv）候选登记。
- 导入：DevSwitch 状态迁移向导 + 导入记录。

## Git 身份（四标签）

- 身份档案：列表/编辑/收编全局身份/gitid 档案迁移。
- 应用与绑定：dry-run 预览→确认应用（全局/仓库/多仓）；目录树绑定/解绑（漂移警告）；生效身份查询。
- 仓库与体检：目录扫描（✓/✗/⚠ 收编）、提交审计（strict 门禁、mailmap 建议）、Git 体检。
- 迁移与凭据：gitid 导入、凭据账号（helper 登录/写入/擦除，token 不可见）、镜像推送。

## 本产品不提供（全局边界）

后台守护/自动修复/任意命令执行/`.mailmap` 写入/token 存储/系统 PATH·注册表修改/多用户共享。各模块"不提供"清单继续有效。
