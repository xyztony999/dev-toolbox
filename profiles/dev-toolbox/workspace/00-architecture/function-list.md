# 功能清单 — DevToolbox 项目上下文

版本：v1.0 | 日期：2026-10-27

## 本机开发者

### 项目

- 登记项目目录：选择目录，查看扫描摘要后确认登记。
- 浏览项目：查看名称、根目录、最近扫描时间与扫描状态。
- 移除登记：确认后只删除 DevToolbox 自有登记，不删除项目内容。

### 项目详情

- 查看仓库：列出路径、工作树类型与识别来源。
- 查看模块：按目录展示模块类型、清单来源与运行时声明。
- 查看要求：显示运行时、原始约束、来源文件、置信度、冲突/未知状态。
- 重新扫描：显示进度与取消入口，完成后展示新增、变化、消失证据。
- 查看异常：权限不足、忽略路径、格式不支持与扫描错误可被定位。
