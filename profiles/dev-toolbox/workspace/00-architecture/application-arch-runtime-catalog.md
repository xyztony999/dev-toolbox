# 应用架构 — 本机运行时发现与登记

版本：v1.0 | 日期：2026-10-27 | 模块：runtime-migration

## 1. 模块与服务

| 分层 | 功能模块 | 服务 | 职责 |
|---|---|---|---|
| 平台支撑域 | 运行时目录 | RuntimeDiscovery | 通过平台适配器产生静态候选，不写状态 |
| 平台支撑域 | 运行时目录 | RuntimeInspector | 校验用户指定目录并提取白名单元数据 |
| 平台支撑域 | 运行时目录 | RuntimeCatalogStore | 登记候选、规范化去重、读取状态 |
| 平台支撑域 | 用户运行时选择 | GlobalSelectionService | 复用用户级状态，显式设置全局默认 |

## 2. 组件关系

CLI 与桌面桥接调用同一 Go 应用服务；服务调用只读文件系统/PATH/平台元数据适配器。扫描候选只存在于响应内，确认登记后才写 DevToolbox 用户状态。前端不扫描目录、不维护第二份状态。

## 3. 质量与副作用

- 文件证据读取限定于白名单文件名和候选根；不跟随根外链接、不遍历全盘。
- 本轮不得执行发现到的任何二进制或脚本。
- 写入前校验候选摘要和状态 revision；原子写入，仅触及 DevToolbox 用户配置目录。
- 来源路径、可用状态与识别置信度在返回结果中明确呈现。

## 4. 功能视图

- 运行时设置：默认选择、已登记清单、不可用实例。
- 发现与登记：扫描范围、候选列表、未知/冲突/重复、登记确认结果。
