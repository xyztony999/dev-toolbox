# 功能清单 — Git 身份管理

版本：v1.0 | 日期：2026-10-28 | 用户类型：本机开发者

## 身份档案

- 新增/更新/删除身份档案；支持签名键、gpgsign、gpg.format、自定义 kv、insteadOf 重写与 host=用户名账号选择器。
- 把当前全局 git 身份收编为档案；扫描发现的 ⚠ 手配身份可预览后收编。
- 列表标注全局生效（★）、仓库本地覆盖（◆）与目录绑定。

## 身份应用与目录绑定

- 应用身份到全局、当前仓库或多仓库；先 dry-run 预览每键写入/清除计划，确认后执行；逐仓返回结果，允许部分失败。
- 查看任意目录生效身份与每键来源；prompt 单行格式供后续会话模块使用。
- 绑定/解绑目录树：绑定即时物化片段；解绑回收片段并对手改漂移如实警告。
- 清除本地/全局身份键。

## 仓库审计与体检

- 扫描目录下仓库的身份与镜像状态；可保存默认扫描目录。
- 提交审计：作者分布、期望身份对照、污染标注与 mailmap 建议；strict 模式作提交前门禁。
- Git 体检：git 版本、凭据助手、insteadOf 冲突、目录绑定健康；只读不修复。

## 镜像与凭据

- 当前仓库镜像推送 list/set/unset；fetch 与凭据通道不变。
- 凭据账号：列出 host/用户名；login 走 helper 自身交互；set/remove 经 credential 协议；token 不显示。

## 档案迁移

- gitid 旧档案预览（含与现有档案的冲突标注）、备份、幂等导入。

## 本模块不提供

后台钩子或守护进程、自动修复、`.mailmap` 写入、token 存储、shell 提示符集成、联合体检聚合。
