# 功能清单 — 会话启动器

版本：v1.0 | 日期：2026-11-03 | 用户类型：本机开发者

## 项目详情页（主入口）

- 「在此打开终端」入口：展开预览卡（每工具生效版本/未注入标注、JAVA_HOME、将前置的 PATH 项数、生效 Git 身份）+ 终端选择 + 启动按钮。
- cwd 可选项目根或任一仓库根。

## CLI

- `dev-toolbox session preview [path]`：打印上下文求值结果与可用终端。
- `dev-toolbox session open [path] [--terminal id]`：启动上下文终端（默认首个可用终端）。

## 本模块不提供

任意命令执行、Windows Terminal 集成、会话外环境刷新、会话生命周期跟踪、SSH/远程。
