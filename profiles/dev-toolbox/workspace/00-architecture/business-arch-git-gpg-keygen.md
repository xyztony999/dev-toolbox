# 业务架构 — Git 身份密钥生成

版本：v1.0 | 日期：2026-11-27 | 模块：git-gpg-keygen

## 1. 业务域与活动

归属支撑业务域（Git 身份增强）。用户为**已有**身份档案生成或选用本机签名密钥，并把签名相关字段写回该档案。不另起独立产品域；依赖 `git-identity-migration` 的 IdentityProfile 与档案更新语义。

| L3 关键业务 | L4 业务活动 | 输入 | 输出 | 边界 |
|---|---|---|---|---|
| 密钥生成 | 生成 OpenPGP 密钥 | 档案 id、算法、有效期、可选口令 | 指纹/密钥 id + 档案签名字段更新 | 调本机 `gpg`；不存口令/私钥 |
| 密钥生成 | 生成 SSH 签名密钥 | 档案 id、算法、可选口令、输出路径策略 | 公钥路径/指纹 + 档案签名字段更新 | 调本机 `ssh-keygen`；`gpg.format=ssh` |
| 密钥选用 | 列出本机可用密钥 | 类型（openpgp/ssh） | 可选密钥清单（指纹/uid/路径等非敏感摘要） | 只读；缺工具时报错 |
| 密钥选用 | 选用已有密钥写回档案 | 档案 id、类型、选中项 | 档案 signingkey + gpg.format（+ 可选 gpgSign） | 不生成；不复制私钥 |
| 公钥导出 | 导出公钥材料 | 类型、指纹或路径、目标（剪贴板/文件路径） | 公钥文本或写出路径 | 只读；路径须用户显式指定 |

## 2. 业务规则

- 目标档案必须已存在；不存在则失败，不隐式新建档案。
- 生成成功后**必须**写回该档案的 `signingkey` 与对应 `gpg.format`（openpgp 或 ssh）；是否打开 `gpgSign` 由用户确认，默认建议打开。
- 允许口令；口令与私钥内容永不进入档案、日志、广播状态或通用桥接结果。
- 预览/dry-run 与真跑同一参数校验；真跑才调本机工具并写档案。
- 写档案沿用既有档案更新语义：只更新签名相关字段，不得清掉 name/email 等无关字段。
- 本轮不做：x509 生成、密钥撤销/删除/改口令、上传密钥服务器、代管私钥。
- 平台：Windows + Linux；缺 `gpg` / `ssh-keygen` 时给出可理解错误，不静默跳过。

## 3. L3 依赖（附录）

| 上游 L3 | 依赖方向 | 下游 L3 | 依赖说明 |
|---------|---------|---------|---------|
| 身份档案（git-identity） | → | 密钥生成 / 密钥选用 | 必须指定已有 IdentityProfile；写回签名字段 |
| 密钥生成 / 密钥选用 | → | 身份应用（git-identity） | 写回后由既有 apply/bind 把签名键落到 git 配置 |

## 4. 业务术语

| 术语 | 定义 | 备注 |
|------|------|------|
| OpenPGP 密钥 | 本机 `gpg` 管理的签名密钥，对应 `gpg.format=openpgp`（或留空按 git 默认） | 本产品写档案时显式落 `openpgp` |
| SSH 签名密钥 | 本机 `ssh-keygen` 生成、供 git 以 `gpg.format=ssh` 签名的密钥对 | 与远程登录用 SSH 钥可共用路径，但本模块只关心签名绑定 |
| signingkey | 写入档案/ git `user.signingkey` 的标识（OpenPGP 指纹或 SSH 公钥路径） | 永不含私钥正文 |
| 口令 | 生成本机密钥时可选的保护口令 | 仅进程内短时使用 |
