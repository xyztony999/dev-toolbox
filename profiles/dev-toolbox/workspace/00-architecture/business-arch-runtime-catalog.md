# 业务架构 — 本机运行时发现与登记

版本：v1.0 | 日期：2026-10-27 | 模块：runtime-migration

## 1. 业务域与阶段

归属平台支撑域。目标是让本机开发者了解可供 DevToolbox 管理的运行时安装，并明确选择哪些实例纳入本机清单。

| L3 关键业务 | L4 业务活动 | 输入 | 输出 | 边界 |
|---|---|---|---|---|
| 本机运行时发现 | 扫描常见位置 | PATH、平台常见位置、用户指定目录 | 只读候选与识别问题 | 不递归整盘、不启动候选 |
| 本机运行时发现 | 核对候选 | 工具、版本证据、安装路径、来源 | 用户可审阅候选 | unknown 与重复项可见 |
| 本机运行时登记 | 确认登记候选 | 候选 ID 与摘要 | DevToolbox 用户级安装清单 | 不复制/移动目录 |
| 用户级运行时选择 | 设置全局默认 | 已登记且路径可用实例 | 更新该工具全局选择 | 明确确认；不影响已开父 shell |

## 2. 业务规则

1. 仅支持七种已登记工具；新工具需扩展注册表与识别器。
2. 扫描是只读预览，重复执行不会改变用户级选择或清单。
3. 只有用户确认的候选才登记；相同规范化路径和工具不重复创建。
4. 静态证据不足时 version 为 unknown，保留原始证据和来源。
5. 项目、目录、仓库及会话覆盖不得通过本机扫描或登记隐式变更全局默认。
