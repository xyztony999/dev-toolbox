# 功能清单 — 本机运行时发现与登记

版本：v1.0 | 日期：2026-10-27 | 用户类型：本机开发者

## 运行时设置

- 查看七种工具的已登记安装、版本、来源、可用状态和用户级默认值。
- 只对可用且类型匹配的安装提供“设为全局默认”，确认后显示作用范围。
- 对旧数据中失效路径显示待重新关联，不静默删除或替换。

## 发现与登记

- 扫描当前 PATH、有限的工具常见目录，或用户指定目录。
- 查看候选工具类型、版本证据、来源路径、识别状态和重复原因。
- 确认后登记一个或多个候选；取消不产生状态变化。
- 部分扫描失败时保留可用结果并显示具体路径和原因。

## 不在本模块操作

下载/安装/卸载、shim/PATH 写入、shell hook、项目会话切换和 Git 身份操作。
