# 应用架构 — 用户级运行时状态迁移

版本：v1.0 | 日期：2026-10-27 | 模块：user-runtime-state-migration

## 模块与服务

| 分层 | 功能模块 | 服务 | 职责 |
|---|---|---|---|
| 平台支撑域 | 用户运行时状态 | LegacyStateReader | 只读探测和解析已知 DevSwitch 状态文件 |
| 平台支撑域 | 用户运行时状态 | RuntimeStateMapper | 生成预览映射、保留未知/不可用状态 |
| 平台支撑域 | 用户运行时状态 | UserRuntimeStateStore | 备份后原子写入 DevToolbox 用户状态并记导入摘要 |
| 平台支撑域 | 用户运行时状态 | GlobalSelectionService | 读取及显式修改用户级默认选择 |

## 依赖与边界

CLI 和 GUI 调用同一 Go 应用服务。Reader 只读旧文件；Mapper 为纯逻辑；Store 只写 DevToolbox 自有数据目录。项目仓库扫描器不读取/写入该状态。安装目录不属于状态迁移的写入目标。

## 功能清单

- “运行时设置”视图：每种工具一个全局默认值和其关联本机实例。
- “导入 DevSwitch”视图：来源检测、映射预览、备份确认、导入结果和重复导入提示。
- 路径不可用条目进入待处理区，允许未来显式重新关联。
