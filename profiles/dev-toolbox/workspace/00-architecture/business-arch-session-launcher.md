# 业务架构 — 会话启动器

版本：v1.0 | 日期：2026-11-03 | 模块：session-launcher

## 1. 业务域与活动

归属核心业务域（项目上下文的"应用"环节）。用户从项目视图一键获得环境正确的终端。

| L3 关键业务 | L4 业务活动 | 输入 | 输出 | 边界 |
|---|---|---|---|---|
| 上下文求值 | 计算生效环境 | cwd（可选项目） | 每工具注入/未注入结论、JAVA_HOME、PATH 前置项、生效 Git 身份 | 只读 |
| 终端选择 | 枚举可用终端 | 平台探测 | 终端列表（PowerShell/cmd/Git Bash/$SHELL） | 只列存在的 |
| 会话启动 | 打开上下文终端 | 终端、cwd、确认 | 新终端窗口（cwd=所选，env=父+注入） | 显式动作；不碰全局 |

## 2. 业务规则

- 未选择/不可用的工具在预览与终端内都如实呈现，不静默回退也不拦截启动。
- 多会话并存；任一会话不修改全局默认与其它会话。
- 启动只创建进程与注入环境，不执行任何项目命令。
