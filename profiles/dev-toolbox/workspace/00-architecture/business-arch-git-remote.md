# 业务架构 — 仓库 Git Remote 管理

版本：v1.0 | 日期：2026-11-03 | 模块：git-remote-management

## 1. 业务域与活动

归属支撑业务域（Git 管理扩展）。用户在单个仓库维度维护 remote 配置。

| L3 关键业务 | L4 业务活动 | 输入 | 输出 | 边界 |
|---|---|---|---|---|
| remote 查看 | 列出 remote 全量信息 | 仓库路径 | fetch/push/镜像/账号视图 | 只读 |
| remote 维护 | 新增/删除/重命名/改地址 | 仓库、名字、url | 本地配置变更 | 显式确认 |
| 镜像推送 | 开启/取消镜像 | 仓库、remote、镜像地址 | pushurl 双目标 | 既有能力不变 |

## 2. 业务规则

- 名字与 url 先校验后执行；非法字符直接拒绝，不落入 git 配置。
- 每次写操作即时回报变更后的 remote 状态；失败如实报错码。
- 删除 remote 前展示其当前地址作为确认上下文。
