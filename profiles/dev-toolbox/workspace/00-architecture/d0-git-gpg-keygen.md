# D0 需求澄清 — Git 身份密钥生成

版本：v1.0 | 日期：2026-11-27 | 模块：git-gpg-keygen

## 需求原文

给 Git 身份管理增加「创建 GPG 密钥」能力（含 OpenPGP 与 SSH 签名密钥）。

## 与既有架构匹配

| 概念 | 匹配 | 说明 |
|------|------|------|
| IdentityProfile | 部分匹配增强 | 已有 signingkey / gpgSign / gpg.format；本模块补「生成 / 列表 / 导出公钥」，成功后**必须**写入指定已有档案 |
| GitIdentity 服务 | 部分匹配增强 | 扩展应用服务与 CLI/桥接；不另起独立产品域 |
| 凭据不落盘 | 完全匹配沿用 | 口令与私钥内容永不进入档案、日志、广播状态 |
| openpgp / ssh / x509 | 部分匹配 | 本轮生成覆盖 **openpgp** 与 **ssh**；x509 仍仅手填，不生成 |

需求类型：**增强**（挂在 git 域新模块条目 `git-gpg-keygen`，依赖 `git-identity-migration`）。

## 已确认规则

1. **密钥类型**：同一入口按类型分支，支持 OpenPGP（本机 `gpg`）与 SSH 签名密钥（本机 `ssh-keygen`，配合 `gpg.format=ssh`）。
2. **档案绑定**：创建必须指定已有 IdentityProfile；成功后自动写入该档案的 `signingkey`、对应 `gpg.format`，并按交互确认是否打开 `gpgSign`（默认建议打开）。不得生成「悬空」密钥却不落档案字段。
3. **口令与私钥**：允许用户设置口令；DevToolbox **永不存储**口令与私钥内容，只调用本机工具，回传指纹/公钥路径/导出内容等非敏感结果。
4. **本轮能力**：创建 + 列出本机已有可用密钥供选择 + 导出公钥。撤销/删除密钥本轮不做。
5. **入口**：CLI 与桌面均提供；桌面挂在档案编辑流程（生成或选用后写回当前/指定档案）。
6. **平台**：Windows + Linux；依赖本机已安装对应工具（`gpg` / `ssh-keygen`），缺失时给出可理解错误，不静默跳过。
7. **用户可选参数**：算法与有效期由用户选择（OpenPGP / SSH 各自给出合理默认与可选集合，具体枚举在 D3/D4 定稿）。

## 业务流程（概要）

1. 用户选定目标档案 → 选择类型（OpenPGP / SSH）→ 选算法与有效期（及可选口令）→ 预览将执行的本机命令摘要（不含口令明文落盘）→ 确认。
2. 调用本机工具生成 → 得到指纹/密钥 id / 公钥材料。
3. 写回档案字段并可选打开提交签名 → 返回结果（可再导出公钥）。
4. 或：列出本机已有密钥 → 用户挑选 → 写入档案（不生成）。

## 业务规则

- 目标档案必须已存在；不存在则失败，不隐式新建档案。
- dry-run / 预览与真跑同一参数校验；真跑才调本机生成并写档案。
- 写档案沿用既有 Profile 校验与全量覆盖语义（仅更新签名相关字段时不得清掉 name/email 等无关字段——按「档案更新」既有 save 语义，非整档 unset）。
- 列表与导出只读；导出公钥可复制/保存到用户指定路径（路径由用户显式选择）。
- 测试隔离：不触真实用户 `~/.gnupg` / 默认 ssh 目录；使用临时 GNUPGHOME / 临时目录。

## 暂不纳入

- x509 证书生成
- 密钥撤销、删除、改口令、上传到密钥服务器
- 代管私钥或口令保险箱
- 自动配置 git 以外的系统信任库

## 角色

本机单用户开发者（与现产品一致）。
