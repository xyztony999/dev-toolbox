# 功能清单 — Git 身份密钥生成

版本：v1.0 | 日期：2026-11-27 | 用户类型：本机开发者

## 本清单概览

在 Git 身份「档案编辑」流程内提供密钥生成/选用/导出；CLI 提供对等子命令。不新增侧边栏一级入口。

## 2.1 本机开发者

**用户类型概述**：本机单用户开发者，维护自己的 Git 身份档案与本机签名密钥。

### 2.1.1 支撑业务域

#### 身份密钥生成

###### 生成与预览

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 生成签名密钥 | 选定档案与类型（OpenPGP/SSH），选算法与有效期，可设口令；预览命令摘要后确认生成并写回档案 | 生成与预览 | 默认建议打开提交签名 |
| 预览生成计划 | 只校验与展示将执行动作与档案字段变更，不调本机生成、不写档案 | 生成与预览 | dry-run |

###### 列表与选用

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 本机密钥列表 | 按类型列出本机可用密钥摘要供挑选 | 列表与选用 | 缺工具时报错 |
| 选用已有密钥 | 将选中项写入当前档案的签名字段 | 列表与选用 | 不生成 |

###### 公钥导出

| 菜单名称 | 功能点描述 | 所属功能子模块 | 备注 |
|---------|-----------|---------------|------|
| 导出公钥 | 复制公钥文本或保存到用户指定路径 | 公钥导出 | 路径显式选择 |

## CLI

- `dev-toolbox git keygen options|preview|create|list|select|export`（写操作需 `--confirm`；create/select 必须带档案 id）。

## 本模块不提供

x509 生成、密钥撤销/删除/改口令、密钥服务器上传、口令保险箱、系统信任库配置、独立「密钥管理」一级页面。
