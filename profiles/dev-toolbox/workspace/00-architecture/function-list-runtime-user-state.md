# 功能清单 — 用户级运行时状态迁移

版本：v1.0 | 日期：2026-10-27 | 用户类型：本机开发者

## 运行时设置

- 浏览 Node、Java、Maven、Gradle、Android SDK、Go、Python 的用户级全局选择。
- 查看每个登记实例的版本、来源、可用状态、可选标签和厂商。
- 对可用实例执行明确的“设为全局默认”；展示该动作只影响后续未被项目/会话覆盖的启动。
- 查看 unresolved 选择的原路径；不会静默清空或改选。

## DevSwitch 导入

- 查看发现的 `state.json` 来源和 schema。
- 预览七种工具的默认选择与运行时条目、缺失路径及重复项。
- 确认新位置备份后执行幂等导入。
- 查看导入结果、备份时间和摘要。
