# 业务架构 — 运行时下载与安装

版本：v1.0 | 日期：2026-10-28 | 模块：runtime-download-install

## 1. 业务域与活动

归属平台支撑域。用户为本机 RuntimeCatalog 获取 provider 提供的运行时安装。

| L3 关键业务 | L4 业务活动 | 输入 | 输出 | 边界 |
|---|---|---|---|---|
| 运行时获取 | 查询可安装版本 | 工具、平台、架构、版本选择 | provider 版本候选及支持情况 | 只读网络查询 |
| 运行时获取 | 预览安装计划 | provider 候选 | 目标、体积/校验信息、风险状态 | 不下载/写入 |
| 运行时安装 | 确认下载与安装 | 计划 ID、摘要、显式确认 | 用户目录安装与 RuntimeInstallation | 不自动设默认/改 PATH |
| 运行时安装 | 查看安装结果 | 安装任务状态 | 成功、部分失败、取消或失败详情 | 不把部分安装伪装为原子成功 |

## 2. 业务规则

- 仅允许应用内注册的工具/provider/URL 模板；前端不能传任意下载 URL。
- 只有 checksum 已验证、归档安全检查通过且 provider 版本与计划一致才登记完成。
- 未知现有目标目录不删除、不覆盖；同版本冲突由预览/错误明确呈现。
- 下载结果只进入用户级安装清单；设全局默认是独立确认动作。
