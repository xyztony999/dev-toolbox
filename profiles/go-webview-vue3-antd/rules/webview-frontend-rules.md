# Go WebView / Vue / Ant Design Vue 规范

- WV-01：桌面宿主为 Go WebView；前端 Vue 3 + TypeScript + Ant Design Vue。不得自行替换为 Electron、Naive UI 或其他宿主。
- WV-02：Vite 静态构建内嵌到 Go GUI；宿主依赖 WebView2/GTK/WebKitGTK 等系统组件，打包说明必须反映真实依赖。
- WV-03：桥接仅允许明确注册的操作；请求/响应/错误/事件含稳定关联标识，验证输入与路径范围，不暴露任意命令/文件访问。
- WV-04：前端不能运行 shell、直接读写用户配置或维护另一份当前环境真值；读取 Go 服务的实际快照并展示来源/作用域。
- WV-05：后台更新 UI 必须经 WebView 宿主允许的派发机制；窗口生命周期、关闭/重开、托盘退出和单实例交互需验证。
- WV-06：长操作有进度、取消、重复点击保护、失败详情与重试；敏感信息不得进入通用状态、事件或错误日志。
- WV-07：核心交互覆盖空状态、未知版本、冲突、部分失败、权限缺失和离线；适配小窗口及键盘操作。
- WV-08：构建至少执行前端类型检查和生产构建，并核对内嵌资源同步；宿主 GUI 编译/启动与 CLI 构建分别报告。
- WV-09：桥接字段、错误码、作用域与 Go 契约逐一对齐后才可标记前端完成；测试使用 fixture/沙箱。

前端根来自业务 slots.frontend_root，默认 frontend；固定依赖版本以实现时 lockfile 为准。
