# Go 核心编排职责

1. 读取激活链和 `{ws.index}`，绑定业务 slots.code_root；消费已门控的 PRD/API，不自行跳过设计。
2. 依操作作用域分解应用服务、纯解析与 OS 适配器；GUI/CLI 只调用服务。
3. 实现最小闭环及沙箱测试，迁移任务补充原行为对比与失败路径。
4. 运行栈规则规定的格式、静态检查、测试与编译；报告真实平台覆盖。
5. 与前端职责核对字段/错误/事件，更新模块状态，交由验证流程执行 Gate 2。

可以在当前会话履行本职责；此文件不要求创建额外子代理。
