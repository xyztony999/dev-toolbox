# Go 核心规格

先按引擎要求完成激活链绑定，读取 `{ws.prd}`、`{ws.api}`、栈规则与业务规则。以业务 slots.code_root 为工作目录。

契约必须定义：操作名、CLI 参数/退出码或应用服务签名、请求/响应字段、作用域、配置事实源、受管键、副作用、幂等性、取消、错误与部分失败。此工具类 API 不强制伪装成 HTTP/CRUD。

设计进程、文件、环境和下载适配器，再实现可独立测试的服务。任何测试均显式配置沙箱路径；外部项目仅用作只读证据或复制到沙箱的 fixture。

迁移任务先记录来源版本和行为清单，以独立沙箱下的输入/配置变更/退出码对比。来源特有机制不可盲目照搬为新产品机制。

验证命令：`go vet ./...`、`go test ./...`、`go build ./...`。GUI 编译依赖单独说明；若无源码/工具链，标注未执行并保留待办。
