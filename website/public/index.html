DevToolbox

把「这个项目用哪套运行时、哪个 Git 身份」收进同一个钥匙盒——可见、可确认、可撤销。

下载 Release 查看源码
  • Node · Java · Go · Python
  • Git 身份全量覆盖
  • 不改父终端 PATH

三件事，一套工具

CLI、桌面客户端与托盘共用同一 Go 应用服务；前端只展示与发出结构化请求。

项目上下文

登记与扫描本机项目，识别 Git 工作树与构建模块，提取版本要求。只读，不跑项目脚本。

用户级运行时

Node / Java / Maven / Gradle / Android SDK / Go / Python：发现、检查、安全安装，预览后显式确认。

Git 身份

多档案全量覆盖、目录绑定、凭据不落盘；dry-run 与真跑同一算法，批量出结果。

显式动作，可预期副作用

安装与切换属于明确用户动作；环境优先作用于启动的会话与子进程。

  1. 01

    选中项目

    从登记列表进入，一眼看到运行时要求与当前 Git 身份。

  2. 02

    预览计划

    下载、校验、目标路径与体积先列出来，再确认执行。

  3. 03

    会话生效

    作用于新开的会话与子进程；不偷偷改写全局默认。

Windows 与 Linux 预构建

从 GitHub Releases 下载安装包，开箱即用。
