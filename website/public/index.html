DevToolbox

先看清这个项目该用哪套运行时、哪个 Git 身份，确认后再改。不会悄悄动你的全局配置。

下载 源码
  • Node · Java · Go · Python
  • 切换 Git 身份
  • 不改系统 PATH

能做什么

命令行和桌面共用同一套 Go 核心，界面只负责展示和发起操作。

项目

登记、扫描本机项目，识别 Git 仓库和构建模块，读出版本要求。只读扫描，不会跑项目脚本。

运行时

支持 Node、Java、Maven、Gradle、Android SDK、Go、Python：发现、检查、安装。先预览，再确认。

Git 身份

多个身份档案，可按目录绑定；应用时完整覆盖，凭据不落盘。可先预览再执行，也支持批量仓库。

怎么用

安装和切换都要你点确认。环境主要作用在新开的终端和子进程上。

  1. 01

    选项目

    打开已登记的项目，直接看到运行时要求和当前 Git 身份。

  2. 02

    先预览

    把版本、校验、目标路径和体积列清楚，你点确认后再动手。

  3. 03

    再生效

    对新开终端和子进程生效，不会悄悄改全局默认。
