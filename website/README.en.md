# DevToolbox Website

**Languages:** [中文](./README.md) · English

Marketing site on Cloudflare Workers Static Assets.

Production: https://dev-toolbox.tonyxyz.com  
Fallback: https://dev-toolbox.zhangxinyi1230.workers.dev

Built-in:

- Light / dark / system theme (cycle via the header control)
- Chinese / English (header language toggle)

## Local preview

```bash
cd website
npm install
npm run dev
```

## Deploy

Requires Wrangler login:

```bash
cd website
npm run deploy
```
